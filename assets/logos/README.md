# Logos RecyNet

Versões PNG com fundo transparente preparadas a partir das duas referências enviadas para o projeto.

- `recynet-colorida.png`: versão de cores fortes, usada nos cabeçalhos públicos, login, cadastro e favicon.
- `recynet-clara.png`: versão clara, usada nos cabeçalhos administrativos.

Os tamanhos de exibição ficam em `components.css` e `cadastro.css`. As imagens mantêm proporção quadrada e o texto RecyNet fornece o nome acessível da marca.
